## Notas da versão 1.3.0 do DLP Downloader

* Foi realizada uma otimização de arquivos, reduzindo o tamanho do software de 530 MB para 360 MB, aproximadamente
* A instalação identifica arquivos necessários ausentes ou alterados antes de iniciar os downloads
* Adicionada uma ferramenta de reparo das ferramentas necessárias
* Os arquivos de suporte e bibliotecas estão organizados na pasta lib
* Foram feitas melhorias nas mensagens e textos da interface de usuário
* Novas janelas pop-up de avisos e orientações
* Correções de bugs menores

## Problemas conhecidos:

* Alguns formatos de origem menos comuns podem não ser compatíveis com esta versão.
